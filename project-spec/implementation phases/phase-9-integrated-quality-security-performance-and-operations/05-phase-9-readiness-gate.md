# Phase 9.5 — Phase 9 Readiness Gate

## Role

You are the integrated production-readiness gate reviewer.

## PASS criteria

Issue **PHASE 9: PASS — PROCEED TO PHASE 10** only if required tests pass for both shells; accessibility, SEO and performance evidence is recorded; security and secret checks have no critical/high unresolved findings; employer-submission protections pass; backups and rollback are tested; preview/production configuration is verified; and every accepted warning has an owner and follow-up date.

## BLOCK criteria

Issue **PHASE 9: BLOCK — DO NOT PROCEED TO PHASE 10** for critical security issues, exposed secrets, failed rollback, public pending data, broken production routing, missing evidence, inaccessible primary flows or unresolved launch-blocking performance/regression issues.

## Required deliverable

Create a dated QA/release PASS/BLOCK record containing evidence links, sign-offs, blockers, owners and exact Phase 10 entry conditions.
