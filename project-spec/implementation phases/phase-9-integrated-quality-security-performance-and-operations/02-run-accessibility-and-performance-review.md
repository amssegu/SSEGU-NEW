# Phase 9.2 — Run Accessibility and Performance Review

## Role

You are the dual-design accessibility and performance reviewer.

## Required work

Test representative mobile and desktop News/Work pages with automated and manual accessibility checks: semantics, keyboard, focus, headings, landmarks, labels, alt text, contrast and reduced motion. Measure Lighthouse goals of 90+ performance, 95+ accessibility/SEO, LCP under 2.5s, CLS under 0.1 and INP under 200ms under realistic mobile conditions.

## Deliverables

Reports with URLs, devices/network, measurements, regressions, fixes and accepted exceptions. Do not claim targets from source inspection alone.
