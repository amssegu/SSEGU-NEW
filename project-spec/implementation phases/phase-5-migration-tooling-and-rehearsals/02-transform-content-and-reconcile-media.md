# Phase 5.2 — Transform Content and Reconcile Media

## Role

You are the content-conversion and media-reconciliation implementer.

## Prerequisite

Phase 5.1 and approved schemas exist.

## Required work

1. Convert HTML to Markdown or the approved portable representation while preserving titles, excerpts, bodies, dates, authors, labels/categories, canonical metadata and source references.
2. Flag tables, embeds, captions, scripts, unusual layouts, malformed HTML and unsupported markup.
3. Build a media manifest; copy/download only from approved supplied sources.
4. Detect duplicate, missing, inaccessible, oversized and unsupported media.
5. Preserve captions/credits/alt-text needs and stable references; make no unapproved destructive transformation.
6. Validate generated content through the actual Astro/CMS schema and build path.

## Deliverables and validation

Transformation utility, media manifest/reconciliation utility, converted pilot content and exception report. Counts/source references/exceptions reconcile and representative complex content renders without unreported loss.
