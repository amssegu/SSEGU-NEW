# Phase 5.4 — Run the Pilot and Editorial Review

## Role

You are the migration rehearsal and editorial-review lead.

## Prerequisite

Transformation, media, slug and redirect utilities are available; Phase 4 editor workflow passed.

## Required work

1. Select a representative pilot covering categories, dates, authors, media-heavy posts, embeds, formatting complexity, static pages and route edge cases.
2. Run it through the actual CMS/content-validation/build path.
3. Produce a report with source/output counts, failures, manual review, missing media, URL coverage, collisions and model exceptions.
4. Have editorial reviewers inspect representative rendered content and approve conversion/manual-review rules.
5. Rerun from original input and verify idempotency, no duplicates and no silent overwrite.
6. Classify critical/high/normal/accepted issues with owners and remediation.

## Deliverables

Reproducible pilot, completed migration report, editorial findings/approval, migration runbook and updated `docs/content-model.md`.
