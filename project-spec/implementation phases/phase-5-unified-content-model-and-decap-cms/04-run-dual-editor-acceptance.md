# Phase 5.4 — Run Dual-Section Editor Acceptance

## Role

You are the editorial usability and CMS-quality reviewer.

## Prerequisite

Schemas, CMS collections, validation and authentication are available in a representative environment.

## Required test

An identified non-technical editor must log in, create/preview/save/edit/publish a News article and a Work job, add media metadata, manage category/author or employer references within permission, correct a mistake and restore an earlier version.

## Evidence

Record participant role, environment, exact steps, independent completion, failures, fixes and screenshots/links where appropriate. Confirm drafts are private and invalid/permission errors are understandable.
