# Phase 5.5 — Phase 5 Readiness Gate

## Role

You are the unified content-model and CMS gate reviewer.

## PASS criteria

Issue **PHASE 5: PASS — PROCEED TO PHASE 6** only if News and Work schemas/Decap fields align; validation runs locally and in CI; admin is excluded from indexing; auth, callbacks, permissions and secrets are evidenced; the editor independently publishes both an article and a job; drafts remain private; media guidance works; and no unapproved account or transactional system has been introduced.

## BLOCK criteria

Issue **PHASE 5: BLOCK — DO NOT PROCEED TO PHASE 6** for schema mismatch, failed editor test, public drafts, unverified authentication, secret exposure, validation bypass, unsafe job fields or scope leakage.

## Required deliverable

Create a dated evidence-backed PASS/BLOCK record with remediation owners and next action. A PASS authorizes employer-submission implementation.
