# Phase 5.2 — Configure Decap for Both Sections

## Role

You are the Decap configuration and editorial-media implementer.

## Prerequisite

Phase 5.1 schemas and validation pass.

## Required work

1. Configure `public/admin/index.html` and `config.yml` for News and Work collections.
2. Keep CMS field names, required values, defaults and media paths aligned with schemas.
3. Configure image formats, upload limits, dimensions, filenames, alt text, caption and credit guidance.
4. Exclude `/admin/` from navigation, sitemap and indexing.
5. Choose direct publishing or editorial workflow only after recording the editorial decision; do not add unnecessary branches or review machinery.
6. Document editor access, onboarding, removal and least privilege.

## Validation

Round-trip representative News article and Work job content through CMS-compatible files and schema validation. Invalid fields and media metadata must fail clearly.
