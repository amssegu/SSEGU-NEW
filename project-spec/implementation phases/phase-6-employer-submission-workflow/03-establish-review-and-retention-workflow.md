# Phase 6.3 — Establish Review and Retention Workflow

## Role

You are the employer-submission operations implementer.

## Prerequisite

The form and secure endpoint pass basic validation.

## Required work

1. Define how editors inspect pending submissions without exposing them publicly.
2. Define statuses, review timestamps, rejection handling, deletion/retention and source verification.
3. Document how an approved submission becomes a manually created Job document in Decap.
4. Ensure the workflow works without optional email notification.
5. If a dashboard is proposed, stop and obtain separate authentication/authorization approval; do not create one implicitly.

## Deliverables

Operational runbook, field/status mapping, retention policy and a redacted review test record.
