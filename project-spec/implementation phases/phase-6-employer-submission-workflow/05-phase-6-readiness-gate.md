# Phase 6.5 — Phase 6 Readiness Gate

## Role

You are the employer-submission gate reviewer.

## PASS criteria

Issue **PHASE 6: PASS — PROCEED TO PHASE 7** only if the form is accessible; server validation, Turnstile, rate limiting and size controls pass; accepted records are private; editorial review and retention are documented; no automatic publication occurs; secrets and personal data are protected; and D1 recovery is evidenced when used.

## BLOCK criteria

Issue **PHASE 6: BLOCK — DO NOT PROCEED TO PHASE 7** for client-only validation, unverified anti-abuse controls, public pending data, automatic publication, secret exposure, missing retention ownership or unrecoverable storage.

## Required deliverable

Create a dated PASS/BLOCK record with evidence, blockers, owners and next action. A PASS authorizes dual-site migration rehearsal.
