# Phase 3.1 — Implement Design Tokens and Base Layout

## Role

You are the main-site design-system and accessibility-foundation implementer.

## Prerequisite

Phase 2 must have a PASS gate. Read the Phase 1 frontend specification and `frontend.png`.

## Required work

1. Establish color, typography, spacing, borders, elevation and responsive-breakpoint tokens.
2. Implement `BaseLayout` with document structure, language, metadata slots, skip link, global styles and shared accessibility behavior.
3. Keep main-site styles self-contained and shared utilities genuinely generic.
4. Define semantic HTML, keyboard, focus, contrast, reduced-motion, image and heading conventions.
5. Add representative fixture content/data for visual and route testing.

## Validation and handoff

Tokens/layout map to the approved specification, baseline checks pass, and no Work namespace/content is added. The foundation is ready for the main-site shell.
