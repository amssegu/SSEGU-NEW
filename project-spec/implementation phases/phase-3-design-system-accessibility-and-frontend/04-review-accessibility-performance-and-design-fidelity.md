# Phase 3.4 — Review Accessibility, Performance and Design Fidelity

## Role

You are the frontend quality and visual-review implementer.

## Prerequisite

All approved routes/modules render with fixture content.

## Required work

1. Review mobile and desktop pages against `frontend.png` and the Phase 1 specification.
2. Test semantic HTML, keyboard operation, focus, heading order, alt text, contrast, reduced motion, labels and errors.
3. Check image formats/dimensions, lazy loading, layout-shift prevention, fonts, JavaScript weight and static output.
4. Run route smoke, lint, type, unit/e2e and build checks.
5. Record deviations with severity, owner and remediation; do not silently accept blockers.

## Deliverables

Responsive/accessibility notes, design-fidelity record, route-test output and resolved findings or explicit blockers.
