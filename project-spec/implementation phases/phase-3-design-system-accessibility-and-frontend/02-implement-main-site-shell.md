# Phase 3.2 — Implement the Main-Site Shell

## Role

You are the main-site shell and responsive-navigation implementer.

## Prerequisite

Phase 3.1 is complete. Read the approved navigation and visual specifications.

## Required work

1. Implement `MainLayout`, masthead, utility bar, primary navigation, approved breaking-news treatment, footer and section navigation.
2. Implement the responsive menu with keyboard operation, visible focus, logical tab order and escape/close behavior.
3. Keep navigation data/configuration separate from presentation where useful.
4. Use semantic landmarks, correct heading hierarchy and deterministic shell empty/error states.

## Validation

Test keyboard navigation, focus, reduced motion, mobile/desktop breakpoints and main-site-only links against the Phase 1 specification.
