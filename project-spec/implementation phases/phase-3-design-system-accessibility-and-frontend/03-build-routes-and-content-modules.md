# Phase 3.3 — Build Main-Site Routes and Content Modules

## Role

You are the main-site page and content-presentation implementer.

## Prerequisite

Phase 3.2 is complete. Use the approved route map, content governance and fixture data.

## Required work

1. Build homepage lead/supporting stories, category labels, latest/top stories, approved newsletter/promotional modules and section navigation.
2. Build article, category/listing, approved search, static-page, RSS, sitemap and 404 routes.
3. Implement typed content accessors; keep queries, sorting, pagination and transformations out of presentation components.
4. Add deterministic empty/error states and route-collision safeguards.
5. Use useful image alternatives, reserved image space, responsive dimensions, lazy loading and minimal browser JavaScript.
6. Keep admin out of public navigation/indexing; add no Work route/content collection.

## Validation

Route smoke tests cover every approved route, internal links, 404, RSS/sitemap, mobile/desktop output and route-collision behavior.
