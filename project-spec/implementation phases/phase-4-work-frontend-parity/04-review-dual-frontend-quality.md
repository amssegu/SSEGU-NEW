# Phase 4.4 — Review Dual-Frontend Quality

## Role

You are the dual-shell accessibility, performance and design-fidelity reviewer.

## Prerequisite

Phase 4.1–4.3 are complete and the current repository builds cleanly.

## Required work

1. Review News and Work at representative mobile and desktop widths.
2. Check semantic headings, landmarks, keyboard controls, visible focus, contrast, alt text, form labels and reduced-motion behavior.
3. Check route collisions, navigation boundaries, console errors, layout shifts, image dimensions and unnecessary browser JavaScript.
4. Compare Work against `sseguwork.png` and News against `frontend.png`; record evidence rather than claiming visual parity from source inspection.
5. Fix only Phase 4 frontend defects; defer CMS, migration and backend concerns to later phases.

## Deliverables

Produce a dual-frontend review record with routes tested, viewport/browser, findings, fixes, accepted deviations and remaining blockers.
