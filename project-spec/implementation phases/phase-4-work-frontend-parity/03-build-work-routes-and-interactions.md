# Phase 4.3 — Build Work Routes and Interactions

## Role

You are the Work route and interaction implementer.

## Prerequisite

Phase 4.2 passes and all Work pages remain fixture-backed.

## Required work

1. Implement fixture-backed listing/detail routes for jobs, internships, career advice, courses and CV resources.
2. Add job cards with employer, location, work arrangement, employment type, deadline and clear application state.
3. Add keyword, location, employment-type, work-arrangement and active/expired filtering with deterministic empty states.
4. Add accessible links from homepage modules and quick links to their route owners.
5. Keep application, employer submission and account controls clearly deferred; `/work/submit-job/` may be an explicitly marked fixture page only.
6. Ensure query strings and route state do not alter News routes.

## Validation and deliverables

Test keyboard operation, focus order, mobile layout, filter behavior, empty results, direct route loads and 404 behavior. Record the fixture content used and any unresolved design decisions.
