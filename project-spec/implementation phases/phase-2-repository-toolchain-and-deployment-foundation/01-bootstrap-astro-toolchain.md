# Phase 2.1 — Bootstrap the Astro Toolchain

## Role

You are the application-foundation implementer.

## Prerequisite

Phase 1 must have a PASS gate. Read its approved route map and frontend specification.

## Objective

Create the first deployable Astro + TypeScript + Tailwind application skeleton.

## Required work

1. Bootstrap Astro with TypeScript and Tailwind using pinned, supported configuration.
2. Add scripts for development, formatting, linting, type checking, unit tests, end-to-end tests, content validation, build and preview.
3. Configure static generation by default and document exceptions.
4. Add a smoke-test page and local preview path proving the toolchain.
5. Keep dependencies minimal and justify client frameworks/server features.

## Constraints

No Work routes/components/content; no database, accounts, R2 or Pages Functions without approved need; no secrets.

## Deliverables and validation

First application commit, working configs/scripts, and clean-checkout install/check/build/preview evidence. The toolchain must be reproducible for Phase 2.2.
