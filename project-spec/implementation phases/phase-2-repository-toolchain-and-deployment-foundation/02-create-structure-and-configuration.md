# Phase 2.2 — Create Repository Structure and Safe Configuration

## Role

You are the repository-structure and configuration implementer.

## Prerequisite

Phase 2.1 local checks pass. Read the structure and organization rules in `techspec.md`.

## Required work

1. Create `src/components/main`, `src/components/shared`, `src/components/ui`, layouts, pages, content, styles, libraries and scripts.
2. Add `public/` foundations and safe robots/admin placeholders only where required by later phases.
3. Add structural `BaseLayout` and `MainLayout` foundations without prematurely implementing Phase 3 design.
4. Add migration/validation/deployment docs and script boundaries.
5. Add Astro, TypeScript, Tailwind, Wrangler and build configuration as needed.
6. Add environment-variable validation, safe `.gitignore`, public-vs-secret documentation and future-template notes.

## Validation and deliverables

Structure matches the specification, secret files are ignored/not bundled, clean build passes, and no Work implementation exists. Deliver structure/configuration, initial layouts, environment docs and future-template notes.
