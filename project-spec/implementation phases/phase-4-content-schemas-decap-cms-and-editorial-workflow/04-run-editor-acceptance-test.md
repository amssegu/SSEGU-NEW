# Phase 4.4 — Run the Editor Acceptance Test

## Role

You are the editorial usability and CMS-quality reviewer.

## Prerequisite

CMS collections, validation and authentication are available in a representative environment.

## Required test

An identified non-technical editor must log in; create an article with title, excerpt, body, image, alt/caption/credit, author and category; preview; save a private draft; edit; publish; correct a mistake; restore an earlier version; and manage category/author references within permissions.

## Evidence

Record participant role, environment, steps, independent completion, screenshots/links where appropriate, failures and fixes. Callback errors, permission failures and invalid content must be understandable.

## Handoff condition

The CMS is ready for migration only when the editor completes the test without developer intervention and drafts remain private.
