# Phase 1.2 — Audit Content, Media and URLs

## Role

You are the main-site content, media and SEO-discovery auditor.

## Prerequisite

Phase 1.1 must have produced a traceable input manifest. Read it and the Phase 0 scope baseline.

## Objective

Turn supplied main-site exports and approved inventories into complete, reviewable inventories and exception reports.

## Required work

1. Audit posts/pages, IDs, original URLs/slugs, titles, descriptions, dates, authors, labels/categories, images, embeds, canonical metadata and special markup.
2. Audit media availability, duplicates, filenames, dimensions, formats, captions, credits and missing assets.
3. Build a complete main-site URL inventory from supplied sources and approved Search Console/exports.
4. Classify each URL as `preserve`, `map`, `redirect`, `404/410` or `manual-review`.
5. Identify slug collisions, duplicates, missing media, unsupported embeds, malformed HTML, unusual layouts, scripts and editorial-review items.
6. Record Search Console clicks, impressions and indexed-URL baseline when supplied, including coverage limitations.
7. Exclude any Work or compromised-domain input and record the exclusion.

## Deliverables

- Main-site content and media inventories.
- URL/redirect inventory with disposition and evidence.
- Special-content/formatting exception report.
- Search Console baseline or explicit unavailable-data record.

## Validation and handoff

Counts reconcile to supplied inputs; important URLs and exceptions are traceable; no prohibited data entered the inventories. The audited set is ready for route and content-model decisions.
