# Fixture Content Model

Phase 2 uses the synthetic metadata in [`project-spec/sample-article-metadata.csv`](../project-spec/sample-article-metadata.csv) and the shared [`article-placeholder.svg`](../project-spec/article-placeholder.svg). Fixture records are not final editorial content.

The expected article fields are `slug`, `title`, `description`, `category`, `author`, `published_at`, `status` and `image`. Phase 4 will replace this fixture contract with validated Astro content schemas and Decap CMS fields.
