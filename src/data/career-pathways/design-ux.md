  - title: Design foundations
    description: Learn design principles and practice visual communication.
    courses:

  - title: Interface tools
    description: Practice layout and prototyping in a design tool.
    courses:
      - figma-learn
    project: Prototype a mobile flow using fictional user needs.
  - title: UX process and portfolio
    description: Plan research, iterate and write case studies.
    courses:
      - google-ux-design-professional-certificate
    project: Publish one case study showing decisions, tests and limitations.
