  - Programming logic
  - HTML/CSS
  - JavaScript or Python
  - Version control
  - Testing

  - title: Programming foundations
    description: Build computational thinking and basic programming.
    courses:
      - cs50x-introduction-to-computer-science

    project: Write a small utility and document its tests.
  - title: Web foundations
    description: Practice semantic markup, styling and responsive layouts.
    courses:
      - responsive-web-design
    project: Build a responsive multi-page site.
  - title: Specialize and demonstrate
    description: Follow a structured front-end sequence and publish a portfolio.
    courses:
      - meta-front-end-developer-professional-certificate
    project: Publish a project with accessible interactions and a README.
